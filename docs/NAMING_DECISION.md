# Publication-facing naming decision

Decision date: 2026-09-14  
Decision status: **provisional until pre-submission conflict review**

The publication-facing project name is:

> **MR-AgentGuard: Failure-Aware Evaluation of Scientific Agents for MRI and MRSI**

The GitHub repository keeps `Science-Agent-Bench-MRI-MRSI` for continuity. Papers,
posters, talks, and figure titles should use `MR-AgentGuard` and state that the
project is an independent prototype. It is not affiliated with, derived from, or
an extension of the ICLR 2025 benchmark named ScienceAgentBench.

## Rationale and checks

- The name describes the central scope: detecting or preventing scientific
  invalidity in MR agent workflows.
- It does not imply clinical safety, diagnosis, or regulatory validation.
- Exact-phrase web searches for `MR-AgentGuard` and `MR Agent Guard` on the
  decision date returned no apparent MRI benchmark or software project. This is
  a preliminary collision check, not trademark clearance.
- `MR-SAFE` was rejected because “MR Safe” is an established MRI device-safety
  label and would invite a clinically unsafe interpretation.

Before submission, repeat title, scholarly-index, GitHub, domain, and trademark
searches. Any conflict or reviewer concern reopens this decision.
