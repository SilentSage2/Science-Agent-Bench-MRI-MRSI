# Tasks

Public task specifications, JSON schemas, generators, and development fixtures will live here. Hidden held-out parameters and reference values must be mounted only for evaluation and must never be exposed to the policy or serialized in trajectories.

The A1 suite is MRI/MRSI-specific and computational: synthetic spectra and phantoms, reconstruction and QC, metabolite quantification, subject-level split auditing, and dynamic-model comparison. Clinical diagnosis and patient-care tasks are explicitly out of scope.
